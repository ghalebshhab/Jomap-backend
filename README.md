# JoMap Backend

Backend services for **JoMap**, a full-stack location and community platform focused on discovering places across Jordan.

## Overview

JoMap helps users explore tourist attractions, restaurants, hotels, markets, and other locations across Jordan.

The platform also supports user accounts, favorites, reviews, ratings, owner-managed listings, media, location-based features, and administrative moderation.

## Features

- User authentication and accounts
- Place and location management
- Favorites
- Reviews and ratings
- Owner-managed listings
- Media and image handling
- Administrative moderation
- Location-based functionality
- REST API endpoints
- Database integration

## Tech Stack

- Java
- Spring Boot
- REST APIs
- JPA / Hibernate
- PostgreSQL
- Maven
- Git & GitHub

## Architecture

The backend follows a layered structure with separation between:

- Controllers
- Services
- Repositories
- Entities
- DTOs
- Validation and business logic

## Project Context

JoMap was developed as a full-stack graduation project with a focus on software engineering, backend development, database design, and location-based functionality.

## Project Status

Completed / maintained as a portfolio project.
